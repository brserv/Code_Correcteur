# Python Starter Project

A minimal Python project scaffold with a venv, simple CLI entry, and pytest.

## Quick Start

1. Create/activate venv (handled automatically here)
2. Install deps
3. Run the app

## Structure

- src/python_starter/main.py: entrypoint
- tests/test_main.py: simple test

## Usage

Run app:

```
python -m python_starter
```

Run tests:

```
pytest -q
```
